1. TV-Regularized D-Flow Inverse Problem

The Gaussian deblurring benchmark optimizes the source variable through D-Flow with total variation regularization to discourage oscillatory reconstructions when the blurred measurement residual is already small.

\[y_{\mathrm{pred}} = \mathrm{DFlow}(z),\qquad y_{\mathrm{obs}} = H(y_{\mathrm{gt}})\]
\[\mathcal{L}(z)=\frac{1}{N}\|H(y_{\mathrm{pred}})-y_{\mathrm{obs}}\|_2^2 + \lambda_{\mathrm{TV}}\operatorname{TV}(y_{\mathrm{pred}})\]
\[\operatorname{TV}(y)=\operatorname{mean}\sqrt{(\Delta_x y)^2+\epsilon^2}+\operatorname{mean}\sqrt{(\Delta_y y)^2+\epsilon^2}\]

The stopping rule remains tied to measurement MSE, not the regularized objective.

3. DLRA Toy ODE

The DLRA toy problem uses the linear matrix ODE

\[A'(t)=L A(t)+A(t)R,\qquad A(t)=e^{tL}A(0)e^{tR}.\]

The solution is guaranteed to remain low rank by choosing the initial condition \(A(0)\) to have rank \(r\). This is not done by making \(L\) or \(R\) low rank. In the implementation, \(L\) and \(R\) are full \(n\times n\) generator matrices built as a random skew-symmetric rotation term plus a smaller symmetric growth/decay term. Since \(e^{tL}\) and \(e^{tR}\) are invertible for all finite \(t\), multiplication by them preserves rank:

\[\operatorname{rank}(A(t))=\operatorname{rank}(e^{tL}A(0)e^{tR})=\operatorname{rank}(A(0))=r.\]

The exact-low-rank experiment in dlra/toy_low_rank_ode.py uses matrix size \(A(t)\in\mathbb{R}^{40\times 40}\) with rank \(r=4\). The initial matrix is constructed as

\[A(0)=W_1\operatorname{diag}(\sigma)W_2^\top,\]

where \(W_1\) and \(W_2\) are random orthonormal bases from QR factorizations, \(\sigma_i=0.5^i\), and all singular values after the first \(r\) are set to zero in the exact-low-rank case. The approximate-low-rank case keeps a decaying full spectrum instead.

The implementation evolves \(Y(t)=U(t)S(t)V(t)^\top\) directly on the rank-\(r\) manifold using projected factor ODEs and QR re-orthonormalization.

4. Dynamic Low Rank D-Flow

The implementation in dlr_dflow/dlr_dflow_demo.ipynb approximates the sensitivity of the pretrained flow

\[\dot{x}_t=v_\theta(t,x_t),\qquad x_0=z,\qquad J_t=\frac{\partial x_t}{\partial z},\qquad \dot J_t=A_tJ_t.\]

For the Gaussian deblurring objective

\[\Phi(z)=\frac{1}{2}\|\mathcal A(x_1(z))-y\|_2^2,\qquad g_x=D\mathcal A(x_1)^\top(\mathcal A(x_1)-y),\]

the exact source gradient is \(J_1^\top g_x\). The notebook uses a scalar baseline and rank-\(r\) residual,

\[J_t\approx\alpha_tI+U_tS_tV_t^\top,\qquad \widehat{\nabla_z\Phi}=\alpha_1g_x+V_1S_1^\top U_1^\top g_x.\]

The scalar baseline follows average log-volume change,

\[\frac{d}{dt}\log\alpha_t=\frac{\operatorname{tr}(A_t)}{d},\]

with the trace estimated by Hutchinson probes. The residual factors are advanced by a first-order Lubich-Oseledets K/S/L projector-splitting update. Only skinny products \(A_tQ\) and \(A_t^\top Q\) are evaluated through batched JVPs and VJPs; the full image-by-image Jacobian is never formed.

Implemented Outer Update

  1. At the first optimizer iteration, initialize a random rank-\(r\) basis and a small core \(S_0=\varepsilon I\).
  2. At later iterations, use the previous approximate source gradient as a source-time basis seed, while resetting the core near zero so that \(J_0\approx I\).
  3. Integrate the flow state and low-rank factors together once from \(t=0\) to \(t=1\).
  4. Compute \(g_x\) at that endpoint, apply the approximate transpose sensitivity, and update \(z\) with Adam.
  5. After \(z\) changes, reinitialize and re-evolve the factors along the new trajectory.
Outcome. The notebook now implements the reinitialize-and-re-evolve strategy described in Sections 9 and 11 of the notes. It no longer performs a duplicate flow integration merely to obtain the current endpoint gradient, and it no longer inserts the current endpoint gradient directly into both initial factor spaces.
Interpretation. This is a dynamic low-rank approximation along generative flow time \(t\), recomputed after every source update. It is not the optional coupled optimizer-time method based on \(p_t\), \(W_t\), and Hessian-vector products. The latter remains a proposed extension in the notes and is not claimed as implemented here.
